# Release policy

There is currently no operational Boot installer, supported host matrix, or
release artifact. The package is a non-operational status scaffold.

A future tool release must be defined by a reviewed tool proposal. Its release
record must identify exact package inputs and digests, source revision,
supported host environments, declared side effects, verification results, and
known limitations. Signing roles and trust distribution remain undecided; no
production key or pin is defined here.

No QEMU or historical Boot-OS artifact establishes release readiness. Boot
releases may not grant provider admission, fetch models, or activate Edge.
