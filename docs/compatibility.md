# Host compatibility

**No host environment is currently supported or hardware-verified.** Boot has
no operational installer or runtime. It runs only when a user invokes its
read-only status scaffold; the target environment for future helper tools has
not been selected.

Any future tool proposal must list exact OS/distribution versions,
architectures, privilege requirements, package manager assumptions, and
offline/online behavior. Compatibility is not inferred from Debian Live, a
QEMU result, or the fact that a Python package imports.
